# v0.1.11

`codex-channels` v0.1.11 adds a more discoverable CLI upgrade path without disturbing machine-readable command flows.

## Highlights

- add an interactive `self-update` flow for the published CLI
- surface arrow-key update choices for the default interactive help path
- persist `skip until next version` state for update prompts
- reuse the same arrow-key menu UX for `plugin-bootstrap` scope selection
- keep JSON-oriented command flows free from automatic update interception
