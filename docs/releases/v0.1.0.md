# v0.1.0 Release Notes

## Summary

`codex-channels` v0.1.0 establishes the first public foundation for a Codex-first, local-first interaction runtime.

This release focuses on a strong OSS base rather than a hosted product surface. It provides the core runtime contracts, local channel runtime, file-backed persistence, Codex app-server bridge primitives, multiple remote backend scaffolds, a Codex plugin wrapper, and release/publish automation scaffolding.

## Included in v0.1.0

### Core runtime
- shared interaction model
- interaction registry and lifecycle states
- runtime publish / resolve / cancel / wait primitives

### Local-first runtime
- local HTTP runtime server
- interaction listing and inspect endpoints
- resolve / cancel endpoints
- file-backed JSON persistence

### Codex bridge
- Codex interactive request mapping
- response/result mapping
- stdio bridge mode
- spawned bridge mode

### Remote backend scaffolds
- Slack
- Discord
- Telegram

### Codex-facing install surface
- plugin wrapper manifest
- `.mcp.json` local bridge wiring
- plugin bootstrap command
- plugin install documentation

### OSS/release readiness
- MIT license
- contributing/security/code of conduct/changelog
- publish dry-run tooling
- release workflow scaffold

## Known gaps after v0.1.0

- inbound reply/callback handling for remote channel backends
- sqlite or stronger persistence backend
- real end-to-end Codex app-server orchestration documentation beyond the current bridge scaffolds
- production-grade channel auth/ops guidance
