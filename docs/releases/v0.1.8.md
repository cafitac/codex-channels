# v0.1.8

`codex-channels` v0.1.8 re-cuts the npm package set after the earlier 0.1.7 CLI artifact was already published without the expected executable payload.

## Highlights

- publishes a fresh package version after the release workflow and tarball path fixes were merged to main
- intended to restore the global install path:
  - `npm install -g @cafitac/codex-channels`
  - `codex-channels doctor`
- keeps the first-run product surface (`doctor`, `demo`, `inspect`, `reply`) intact
