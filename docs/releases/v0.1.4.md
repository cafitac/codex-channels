# v0.1.4

`codex-channels` v0.1.4 prepares the next publishable release after the 0.1.3 packaging regression.

## Highlights

- Clean workspace builds now regenerate `dist/` outputs before pack/publish flows.
- Stale `tsconfig.tsbuildinfo` artifacts are no longer tracked or relied on.
- `npm test` and `npm run pack:preview` now force a real build first.
- The CLI adds `submit`, a compact local runtime command for one interaction roundtrip.

## Why this release matters

v0.1.3 could produce npm tarballs that missed compiled `dist/` outputs on clean runners. That made downstream installation and integration flows brittle even when local development happened to work.

v0.1.4 fixes that release-path problem directly so the published packages can once again be consumed from a clean machine.
