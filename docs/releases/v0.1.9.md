# v0.1.9

`codex-channels` v0.1.9 fixes the stale TypeScript build cache problem that kept some published workspace tarballs source-only.

## Highlights

- the build script now deletes each workspace `dist/` directory and `tsconfig.tsbuildinfo` before rebuilding
- tracked `tsconfig.tsbuildinfo` files are removed from the repo
- the goal is to make the publish tarballs consistently match the verified build outputs on clean runners
