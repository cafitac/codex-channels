# v0.1.5

`codex-channels` v0.1.5 fixes the GitHub Actions publish path after 0.1.4 still shipped source-only tarballs.

## Highlights

- release workflow now publishes from each workspace directory directly
- clean-run package artifacts keep `dist/index.js` in the published tarball
- the package-first Hermit install path can target the published CLI/runtime version intended for fresh-machine setup
