# v0.1.19

`codex-channels` v0.1.19 installs Codex-visible shortcut skills for the most important operator actions so users can discover them directly from the skill list.

## Highlights

- install shortcut skills such as `operator-status`, `next-step`, `channels-doctor`, `channels-demo`, `channels-pending`, and `channels-reply-latest`
- keep the main `codex-channels` skill as the top-level router
- improve Codex-side discoverability when shell-style subcommand autocomplete is not enough
