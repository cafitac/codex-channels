# v0.1.16

`codex-channels` v0.1.16 adds a one-shot operator summary so Codex-guided sessions can see runtime state, actionable work, and the next best step in one command.

## Highlights

- add `codex-channels operator-status` as a compact executable summary
- make the skill and docs treat `operator-status` as the best first operator check
- keep the lower-level doctor, pending, inspect, and reply commands for detailed control
