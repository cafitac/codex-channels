# v0.1.6

`codex-channels` v0.1.6 fixes the final gap in the GitHub Actions publish lane by publishing the exact tarballs that were just packed and verified.

## Highlights

- release workflow now packs each workspace into `release-tarballs/*.tgz`
- GitHub Actions publishes those tarballs directly instead of repacking workspaces during publish
- this keeps the published npm artifacts aligned with the tarballs already verified by `npm run pack:preview`
