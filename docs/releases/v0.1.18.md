# v0.1.18

`codex-channels` v0.1.18 adds `next-step`, a small action router that helps Codex-guided sessions keep the local operator loop moving once runtime state has been summarized.

## Highlights

- add `codex-channels next-step` as a state-based action surface
- keep `operator-status` as the summary surface and `next-step` as the action surface
- preserve explicit low-level commands for detailed debugging and control
