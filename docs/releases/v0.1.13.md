# v0.1.13

`codex-channels` v0.1.13 reduces the shell friction in the local interaction loop by adding faster inspection and reply commands for Codex-guided sessions.

## Highlights

- add `codex-channels pending` to show actionable interactions newest-first
- add `codex-channels reply-latest` to answer the newest pending interaction without copying the id
- update the `codex-channels` skill and docs to present the local loop as a guided operator flow
