# v0.1.10

`codex-channels` v0.1.10 is the first release that includes the user-scope-first bootstrap behavior in the published CLI.

## Highlights

- `plugin-bootstrap` now defaults to user scope unless the caller explicitly chooses workspace scope
- interactive shells can ask whether the user wants a user-level or workspace-local install
- the generated plugin root is now a real plugin directory instead of a self-referential workspace symlink
