# v0.1.7

`codex-channels` v0.1.7 fixes the final GitHub Actions publish bug from v0.1.6 by publishing the packed tarballs as explicit file paths.

## Highlights

- release workflow now publishes `./release-tarballs/*.tgz` instead of ambiguous bare paths
- this avoids npm misreading the tarball names as git/package specs during GitHub Actions release
- the intended outcome is that the published npm artifacts exactly match the tarballs already verified by `pack:preview`
