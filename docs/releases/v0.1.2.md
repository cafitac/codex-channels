# v0.1.2 Release Notes

## Summary

`codex-channels` v0.1.2 is a patch release cut from the latest green `main` branch after adding local preflight commands and release-flow hardening.

## Included in v0.1.2

- `npm run preflight:ci` for local CI-equivalent checks
- `npm run preflight:release` for local release-critical verification
- publishing/release docs updated around the preflight flow
- all prior v0.1.1 runtime, bridge, plugin, and backend scaffold work

## Verification completed

- `npm run preflight:ci`
- `npm run publish:dry-run`
- latest GitHub Actions CI on main passed before tagging

## Why this release exists

`v0.1.1` was tagged before the final release-preflight improvements landed. Rather than rewriting the existing tag, `v0.1.2` captures the latest green state of `main` and becomes the new release candidate.
