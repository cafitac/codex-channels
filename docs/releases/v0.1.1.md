# v0.1.1 Release Notes

## Summary

`codex-channels` v0.1.1 is a follow-up release focused on release automation correctness.

The main goal is to ensure CI and release workflows succeed on fresh GitHub Actions runners by separating source-based typechecking from build-mode declaration emission.

## Included in v0.1.1

- source-based `npm run check` via `tsconfig.check.json`
- build-safe shared tsconfig configuration
- release-safe package tsconfig exclusions for test sources
- continued green local verification and publish dry-run checks

## Verification completed

- `npm run check`
- `npm run build`
- `npm test`
- `npm run publish:dry-run`

## Why this release exists

The original `v0.1.0` tag was created before the final CI/release build fixes landed. Rather than rewriting the existing release tag, `v0.1.1` captures the same product surface plus the necessary automation/build correctness fixes.
