# v0.1.3 Release Notes

## Summary

`codex-channels` v0.1.3 is a packaging correction release. The main change is that the CLI package now publishes under the scoped npm name `@cafitac/codex-channels`, which avoids the permission conflict on the unscoped `codex-channels` package name.

## Included in v0.1.3

- CLI package renamed to `@cafitac/codex-channels`
- workspace versions aligned to 0.1.3
- no functional runtime regression intended beyond the package naming correction

## Why this release exists

The release workflow successfully published the scoped workspace packages during the 0.1.2 attempt, but npm rejected publication of the unscoped CLI package with HTTP 403 because the package name was not available to the current npm credentials. Moving the CLI to the matching `@cafitac` scope resolves that final blocker.
